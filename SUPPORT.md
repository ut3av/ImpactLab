# Getting Support for NIYAMLENS

We want to help you run, test, and contribute to **NIYAMLENS: See the Rule. Understand Its Impact.**

---

## 1. Documentation & Architecture References

Before opening an issue or seeking help, check the project documentation:

* **[README.md](README.md)**: High-level overview, quick start, and architecture.
* **[Product Requirements (prd.md)](prd.md)**: Feature requirements, scope boundaries, and acceptance criteria.
* **[Architecture Guide](docs/ARCHITECTURE.md)**: Deep dive into the backend pipeline, retrieval engine, and 3D plot system.
* **[Data Sources](docs/DATA_SOURCES.md)**: Complete breakdown of the *M.P. Bhumi Vikas Rules, 2012* datasets and version limitations.
* **[Development Guide](docs/DEVELOPMENT.md)**: Local environment setup, dependencies, and troubleshooting.
* **[Testing & Evaluation](docs/TESTING.md)**: Unit testing and evaluation results across the 17 benchmark questions.
* **[Deployment Guide](docs/DEPLOYMENT.md)**: Containerization and production setup.

---

## 2. Reporting Issues & Questions

* **Bug Reports:** If you encounter unexpected behavior, incorrect citations, or calculation failures, please open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
* **Feature Requests & Regulatory Suggestions:** To suggest new calculation modules or UI improvements, submit a proposal via the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).
* **Security Concerns:** For vulnerability disclosures, please review [SECURITY.md](SECURITY.md) and report privately.
